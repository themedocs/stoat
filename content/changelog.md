Every released version of Stoat, newest first. Current version: **1.3.1**, which
needs WordPress 6.5 and PHP 7.4. Update from **Dashboard → Appearance → Themes**
like any other WordPress.org theme.

## 1.3.1

*Released August 8, 2026*

- The theme is now published by Owldraft. Theme author, author URI, and theme URI have been updated.
- Documentation has moved to [themedocs.github.io/stoat](https://themedocs.github.io/stoat/) and the demo to [stoat.themepreview.site](https://stoat.themepreview.site).
- The footer theme credit links to the new theme URL.

## 1.3

*Released July 17, 2026*

- New Customize > Layout section: set the content width and the narrow reading column in pixels, then pick Narrow or Full for archives, pages, and posts independently.
- New per-page override: the page editor's "Page options" box can set a page's content width to Narrow or Full, or leave it on the Customizer default.
- New Customize > Header section: "Header skin" (Light or Dark), "Header background color" and "Header text color" (leave either empty to follow the skin), and "Header padding".
- New header button: give it text and a link in Customize > Header to add a call-to-action to the header bar, in Primary, Black, White, or Outline style, optionally opening in a new tab. On mobile it moves into the off-canvas menu, full width.
- New in Customize > Single Post: "Show featured image (top)", which puts the featured image above the post content along with its caption. Off by default.
- New in Customize > Footer: "Footer padding".
- The footer now follows the content width set above it instead of always using the reading column.
- Button blocks in the editor now match the front end, and the Details block is styled.

## 1.2.2

*Released July 16, 2026*

- New in Customize > Typography: "Navigation font" (defaults to whatever the headings use), "Heading font weight", and "Heading letter case".
- New in Customize > Style: "Meta text color", for the date, categories, and comment count.
- New in Customize > Blog / Archive: "Thumbnail ratio" (square, landscape, portrait, or the image's original ratio) and "Thumbnail width" (a pixel size, or a percentage that tracks the post row).
- Styled the core Query Loop blocks — post title, featured image, date, terms, author, excerpt, and pagination now match the theme's own archive.
- Fixed: a 404 URL rendered the full post archive underneath the "Nothing found" heading instead of just the message and a search form.
- Fixed: two roles sharing one font family emitted that family's @font-face rules twice.
- Heading spacing and list indentation now apply everywhere, not only inside post content.
- Footer credit links to the canonical theme URL.
